暖心同行 v7.3｜統一登入與原本介面（過渡整合版）

這一版完成：
- index.html 志工端和 admin.html 幹部端均需要 Firebase 代號＋PIN 登入。
- A0001 管理後台需確認 Firebase roles 權限。
- 登入後使用「雲端任務」選單，即可使用原本已驗證的 sync 系列清點、派發及審核，不再重複輸入 PIN。
- 原本的六個志工分頁與幹部舊畫面仍保留，可以返回原本習慣的介面。
- 透過 v7.3 Service Worker 修正舊版快取造成的 JS 配置殘留。

尚未完成（請務必注意）：
- 原本的公告、今日服務、聊天室、品號資料以及舊版紀錄大多仍在 localStorage；不會因為登入而自動雲端同步。
- 本版不是完整雲端資料整合版；雲端同步只涵蓋既有 sync 清點派發和審核。
- 原本的本機示範志工身分切換暫時保留，不代表有權讀取雲端他人資料；請勿填入真實個資。
- iframe 方式嵌入原本的 sync 功能，後續應將共用清點元件轉成單頁而非 iframe。

部署方法：
1. 先備份原本 GitHub Volunteer 所有檔案。
2. 解壓縮本更新包，將檔案（不是資料夾）上傳到 GitHub Volunteer 根目錄，Commit changes。
3. 此包故意不包含 firebase-config.js，絕對不要覆蓋目前已成功登入的設定。
4. 用無痕視窗開啟 /Volunteer/，V0001/PIN 登入；/Volunteer/admin.html 用 A0001/PIN 登入。
5. 若舊版已安裝 PWA，需重整或移除已安裝應用重新開啟。
6. 不要把這個過渡整合版當成已完成所有雲端功能的正式營運版。
