# 暖心同行｜志工服務 PWA v1（可操作示範版）

本版是**前端單機原型**：志工端與管理端可以切換，具有活動報名、簽到／簽退、時數待審核與核准、公告、匯出示範資料。資料存放在當前裝置的 localStorage，**不同裝置不會同步**，切換管理端不是正式身分驗證，請勿上傳真實志工名冊或敏感資料。

## GitHub Pages 上線
1. 建立新的公開 GitHub repository（建議與遊戲網站分開，例如 volunteer-pwa）。
2. 把本 ZIP 解壓後的檔案全部上傳到儲存庫根目錄。
3. Settings → Pages → Deploy from a branch → main / (root) → Save。
4. 網址開啟後，用瀏覽器「加入主畫面」。Android 通常可用「安裝應用程式」，iPhone Safari 使用分享 → 加入主畫面。
5. 修改服務工作者快取後，需要重新整理或重新開啟 PWA 才會看到更新。

## 正式系統下一階段
- Firebase Authentication：志工與管理者登入（不使用前端按鈕假裝權限）
- Firestore：志工資料、活動、報名、簽到、時數、公告；設定嚴格的 Security Rules
- 簽到採伺服器時間，限制活動時段／地點，幹部審核與稽核紀錄
- 多人同時報名的名額與重複報名需由交易機制保障
- 進階：LINE／Email 通知、CSV/Excel 匯出、審核、幹部值班、權限

**提醒**：本地示範的簽到／時數僅供體驗，不可作為正式服務紀錄。
