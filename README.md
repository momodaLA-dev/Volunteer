# 暖心同行｜志工服務 PWA v3（本機示範）

## 使用方式

將 ZIP 解壓縮，**全部檔案平放於網站根目錄**並部署到 HTTPS 靜態網站（例如 GitHub Pages）。
- `index.html`：志工端
- `admin.html`：幹部管理端（目前僅示範入口，未驗證身分）

建議先在同一瀏覽器的兩個分頁測試，因為示範資料使用 localStorage；不同手機**無法同步**。

## 操作流程

幹部端：名冊新增志工 → 排班頁建立日期／上午或下午班次 → 指派志工及工作項目 → 工作追蹤檢查是否確認／完成 → 清點紀錄查看與 CSV 匯出 → 公告／留言。

志工端：首頁選示範身分 → 查看自己的今日及未來服務 → 確認收到安排 → 工作完成／問題回報 → 物資清點（倉別／品號／數量／效期） → 查看公告／留言。

自主報名：**保留設計，不啟用按鈕，不接受報名。**

## 限制與正式上線前必要工作

1. 現階段沒有 Firebase 登入、資料庫與 Security Rules。分成 index/admin 兩頁 **不是權限隔離**；知道 `admin.html` 網址仍可開啟，不可直接給正式志工使用。
2. 示範身分切換僅為體驗不同志工的任務列表；正式版應使用登入帳號識別志工，不可讓使用者自由切換。
3. 留言板不是即時聊天室，公告、清點、班次等只存在本機 localStorage。同一裝置同瀏覽器分頁可能同步；不同裝置不會同步。
4. 先用示範名字及假資料測試，請勿輸入真實姓名、聯絡資訊或敏感資料。
5. 正式雲端資料庫需由伺服器規則限制：志工只能讀取自身指派與記錄、寫入自己的確認／清點／留言；幹部可管理班次名冊；清點與公告須保留審核、操作紀錄及資料留存政策。
6. 真正的即時聊天、推播、時數審核、跨裝置同步待下階段實作。
