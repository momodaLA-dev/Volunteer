# 暖心同行 v6（本機示範）

將所有 11 個檔案上傳 GitHub Pages 根目錄，進入 `/Volunteer/`（志工）與 `/Volunteer/admin.html`（幹部）。

## 無限複點測試
1. 在志工端選擇示範志工小安，新增「清點單」，清點一筆以上並送出。
2. 幹部端進入「清點審核」，選擇該單，指派不同的志工複點。
3. 志工端改選被指派志工，進入「物資清點」的「我的待複點任務」，獨立輸入所有筆數。過程不顯示上一版的數量或效期。
4. 複點志工送出後，幹部查看版本差異，可繼續指派任意多輪，或選擇一個版本並結單。
5. 正式庫存僅在最後核准時更新一次；本版只是本機示範數據。

## 注意
- 所有資料目前存在相同瀏覽器、相同網站網址的 localStorage，**不同手機不會同步**。請勿輸入真實個資／真實庫存。
- 志工身分選單不是真正登入；幹部頁網址無權限保護。要正式上線須使用 Firebase Authentication、安全規則，以及具原子交易/冪等保護的後端結單程序。
- 清冊 CSV UTF-8 匯入／匯出沿用 v5.1。
- iPhone LINE 內嵌瀏覽器仍可能因系統鍵盤調整視窗而移動，v6 已減少自動 focus/滾動並保持欄位與按鈕高度，需實機確認。
- 複點依初點**項次數**逐筆獨立輸入；若現場發現新增或遺漏品項，需要另行設計增漏項補登工作流，不能當作正式盤點依據。
