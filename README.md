# 暖心同行｜志工服務 PWA v5（本機操作測試版）

## 部署
解壓縮後，請將所有 10 個檔案（不要整個資料夾）上傳 GitHub 儲存庫 **Volunteer** 根目錄。GitHub Pages 設定 main / (root)。

志工端 `https://momodala-dev.github.io/Volunteer/`
幹部端 `https://momodala-dev.github.io/Volunteer/admin.html`

請確認網址 **Volunteer 大寫 V**。更新後可用無痕視窗測試；若已安裝舊 PWA，可能需要重新整理或移除舊版後重新安裝。

## 重要：尚非正式雲端版
目前是同一瀏覽器、同一網址網域內的 **localStorage 示範版**。**志工手機與幹部電腦之間不會自動同步**！請在同一電腦、同一瀏覽器的兩個分頁（`index.html` 與 `admin.html`）測試完整流程。不同瀏覽器、無痕視窗會有不同示範資料。沒有登入驗證、正式權限或正式庫存資料庫；請勿輸入真實個資，勿用來做正式進貨或正式庫存。

## 試用操作
1. 幹部端 → 匯入盤點清冊 → 下載 CSV 範本 → 在 Excel 編輯後另存 CSV UTF-8 → 選擇志工、上傳。
2. 同一瀏覽器另一分頁志工端 → 通知首頁選同一位示範志工 → 物資清點 → 找到派發清冊。
3. 可依清冊順序核對，也可自由搜尋倉別、品號；按「確認無誤」或「修改異常」。
4. 所有項目核對完畢後送審；幹部端清點紀錄 → 審核 → 核准或退回。
5. 進貨模式：志工端物資清點 → 建立清點單（名稱只輸入一次）→ 逐筆連續新增（手機鍵盤 Enter/下一步）→ 統計 → 整單送審。
6. 幹部端「管理總覽」可查看示範盤點完成率及待審單；「清點紀錄」可查看示範庫存。匯出 CSV 可用 Excel 開啟。

## 使用限制與下階段
- 目前 **僅支援 CSV UTF-8 批次匯入**，不是原生 XLSX 上傳；Excel 可另存 CSV。
- 清點進度自動保存在本機瀏覽器；已載入頁面可離線繼續，但跨手機同步、離線佇列上傳及帳號綁定仍需 Firebase Authentication / Firestore 與安全規則。
- 原始 Excel 盤點列保留 V1；志工核對後會保留相應原始欄位與修改操作紀錄；目前為基礎示範，不是完整不可竄改的稽核記錄。
- 盤點核准在示範庫存中以「倉別＋品號＋效期」分組設定盤點後數量；正式系統還需設計批次與重複盤點的衝突鎖定、盤點涵蓋範圍、帳務覆核。
- 本機示範資料不要用於正式協會管理。正式版必須具備安全登入、管理者角色、伺服器時間、雲端交易及備份。


## v5.1 調整（2026-10-20）
- 志工建立作業單時可選「清點單（進貨／捐贈）」或「盤點單（倉儲核對）」。管理員匯入的盤點清冊維持既有派發方式。
- 逐欄確認時固定左側「上一步」，右側同一位置「下一步」，最後一步右側改顯示「新增本筆」。
- v5.1 新輸入與 CSV 盤點範本使用六碼效期 YYYYMM（年月），例如 202712；匯入須為 6 碼。舊版已暫存在本機的 8 碼效期需重新檢查、轉換才能修改或重新送審，請在測試資料上先驗證。
- **目前仍是同一瀏覽器 localStorage 示範，不是跨手機雲端服務；勿作為正式庫存或人員身分紀錄。**
