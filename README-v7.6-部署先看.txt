暖心同行 v7.6｜雲端任務補強更新

重要：上傳網站檔案後，還必須到 Firebase Console → Realtime Database → 規則，貼上 database.rules.json 並按「發布」。否則雲端草稿與名冊會顯示權限錯誤。

1. ZIP 不包含 firebase-config.js，請勿覆蓋既有正確設定。
2. 小樂 V0003 必須先在 Firebase Authentication 建立測試 Email/Password 帳號，內部識別 email 目前寫為 v0003@gmail.com（如建立不同 Email，需修改 sync.js 的 accounts 對應）；建立後由幹部在「志工帳號綁定」貼上其 UID。請勿在聊天中貼密碼。
3. V0001 小安、V0002 小恩使用已建 Firebase UID。
4. 雲端清點任務：輸入中的數量與效期先存本機，再延遲同步到 /drafts/<UID>/<taskId>。跨裝置請先等待「雲端草稿已儲存」再換裝置；不可同時在兩台編輯同一張草稿（目前沒有自動合併衝突）。
5. 幹部可封存/還原單據，並永久刪除尚未送審的測試任務；有志工送審的正式紀錄不提供永久刪除。封存不釋放雲端容量。
6. 原始志工首頁的公告/今日服務/聊天/原清點/我的紀錄仍有本機資料，尚未完成全面跨裝置同步；只有 Firebase 雲端任務與雲端草稿跨裝置同步。
7. 清點複點 V1/V2/V3 輪次沿用舊實作，異常品號自動篩選/同時編輯衝突鎖定/正式結單仍待開發。
8. 本更新包經靜態語法/規則 JSON 檢查，無法在此代替真實 Firebase 權限與跨裝置測試。請先備份專案和重要紀錄，使用假資料小範圍測試。
