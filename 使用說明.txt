1. 上傳 relay-diagnostic.html 到 GitHub Volunteer 根目錄，不要覆蓋 index.html 或 admin.html。
2. 備份 Firebase Realtime Database 目前規則；檢查隨附 database.rules.json 是否保留你目前發布的所有規則。此檔以先前的規則版本為基礎，線上規則若較新，切勿整份覆蓋，請將 cloudDiagnostics/relay 區塊合併進目前規則。
3. 正確發布規則後開啟 https://momodala-dev.github.io/Volunteer/relay-diagnostic.html
4. 分別使用不同瀏覽器：小安 V0001 發起 → 幹部 A0001 轉交 → 小恩 V0002 回覆 → 幹部 A0001 確認。
5. 測試失敗，點「複製記錄」提供給我。
6. 全程假資料，請勿輸入正式單據或個資。只有幹部可重設這一筆診斷紀錄。
